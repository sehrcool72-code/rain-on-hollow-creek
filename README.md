# Rain on Hollow Creek

A two-player psychological horror game. Marcus and Tessa rent a cozy A-frame for their anniversary. The host answers every
message within minutes. He has never left the house.

Play together online, or alone with an AI partner.

## Download

**Windows:** download **[HollowCreekLauncher.exe](https://github.com/sehrcool72-code/rain-on-hollow-creek/releases/download/launcher/HollowCreekLauncher.exe)** and run it. Windows may say it protected your PC from an unrecognised app: click **More info**, then **Run anyway**.

**Linux:** download **[HollowCreekLauncher-linux-x64](https://github.com/sehrcool72-code/rain-on-hollow-creek/releases/download/launcher/HollowCreekLauncher-linux-x64)**, then run:

```
chmod +x HollowCreekLauncher-linux-x64
./HollowCreekLauncher-linux-x64
```

Click **Install** (about an 800 MB download, 1.3 GB on disk). The launcher keeps the game updated from then on.

## Playing together

1. Both players install the game with the launcher.
2. One player chooses **Open online lobby** and copies the invite.
3. Send the invite to the other player, who joins with it.
4. Pick characters, ready up, and the host starts.

Windows and Linux can play together. Both need the same version, so open the game through the launcher.

This repository only holds the game's downloads.
